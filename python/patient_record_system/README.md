# Patient Record Management System

A simple and efficient web app to add, edit, delete, and view patient records — built using **Streamlit** and **pure Python** (no external database or libraries).

---

## Problem Statement

Small clinics and healthcare startups often need a lightweight system to manage basic patient information without the complexity or cost of full hospital management systems. Many available solutions are too complex, expensive, or overbuilt for simple use cases.

## Solution

This project provides a basic **Patient Record Management System** where users can:
- Add new patient details (name, age, gender, condition)
- Edit or delete existing patient records
- View all current patient records in a clean, organized layout
- Navigate easily between tasks using a sidebar

The app uses **Streamlit's session state** to temporarily store data during user sessions — no database setup required!

---

## Features

- **Add Patients**: Enter patient data and save it easily
- **Edit Patients**: Update any patient's details
- **Delete Patients**: Remove patient records if necessary
- **View Patients**: Browse all existing records
- **Sidebar Navigation**: Switch between tasks seamlessly
- **Clean UI**: Built for clarity and usability

---

## How to Run

1. Install Streamlit
pip install streamlit
2. Clone this repository
3. Run the app:
streamlit run app.py
