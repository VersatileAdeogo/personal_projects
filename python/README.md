# Python Projects Collection

This folder contains a collection of mini-projects and apps built using **pure Python** — without any external libraries like `numpy`, `pandas`, or `scikit-learn`.

The goal of this collection is to showcase my understanding and practical use of **core Python programming concepts**, including:

- Variables and data types
- Functions and conditionals
- Loops and control flow
- Dictionaries and lists
- File I/O
- Modular programming
- Basic user interfaces using [Streamlit](https://streamlit.io)

Each project is designed to solve a small problem — often in the context of healthcare — while demonstrating clean code structure and good practices.

This serves as a demonstration of my foundational Python skills and problem-solving approach, forming part of my journey towards becoming an AI/ML engineer focused on building health-related solutions.

> All apps can be run using Streamlit, and each folder contains a `requirements.txt` file for easy setup.

Feel free to explore the individual apps and check out the source code to see how each Python concept is applied in practice.
